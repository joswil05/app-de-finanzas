## Implementación

Se crearon seis npm workspaces, configuración estricta TypeScript, ESLint, Vitest con proyectos node/jsdom y exclusión explícita de rules/e2e, configuración separada de rules y Playwright con emuladores/demo-finanzas y build servido. Todos los workspaces ejecutan comprobación real de tipos y build. CSS Modules lo soporta Vite sin dependencia adicional; no se creó diseño funcional.

Versiones exactas obtenidas del registro oficial npm y lockfile. Se conservó Node24.14.1/npm11.11.0/Java21.0.12.1 instalados. TypeScript6.0.3 y jsdom29.1.1 sustituyen versiones nuevas incompatibles con el conjunto instalado; detalle en `docs/operacion/versiones.md`. Se añadió fake-indexeddb6.2.5 solicitado para pruebas offline de T05.

Los paquetes compartidos incluyen ES2023+DOM para tipos estándar TextEncoder/structuredClone/WebCrypto disponibles en los tres entornos; el dominio debe seguir libre de window/document/storage. El build TypeScript6 tiene rootDir explícito del monorepositorio para imports de fuentes locales. Los paquetes privados exportan src y los empaquetadores finales resuelven esos fuentes.

Vite consume .env desde raíz; .env.example contiene exclusivamente valores públicos ficticios y nombres comentados para carga externa de secretos. No existe allowlist de propietario único: el aislamiento funcional por UID se implementa en sus tareas. Firebase usa proyecto ficticio demo-finanzas en emuladores. Los Workers de arranque responden503, no tienen cron y su build usa exclusivamente dry-run. No hay publicación ni integración real implementada por el bootstrap.
